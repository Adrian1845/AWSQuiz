# Amazon AppFlow

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Transfiere datos entre aplicaciones SaaS y servicios AWS.

## Cuándo elegirlo

Integraciones de datos administradas.

## Detalles que deciden la respuesta

- Configura flujos entre aplicaciones SaaS y destinos AWS sin construir conectores desde cero.
- Elige disparadores, campos y programación según el flujo de datos.

## Caso basado en escenario

**Situación:** Registros de Salesforce deben llegar a S3 de forma programada.

**Elección:** AppFlow. La pista decisiva es integraciones de datos administradas.

## Diferencia importante

DMS migra bases de datos; AppFlow integra aplicaciones SaaS.
