# Amazon DocumentDB

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Base de documentos compatible con API de MongoDB.

## Cuándo elegirlo

Aplicaciones orientadas a documentos.

## Detalles que deciden la respuesta

- Usa modelo de documentos con compatibilidad de API MongoDB para casos compatibles.
- Verifica las funciones de MongoDB que la aplicación necesita antes de migrar.

## Caso basado en escenario

**Situación:** Una app usa consultas de documentos tipo MongoDB y busca servicio administrado.

**Elección:** DocumentDB. La pista decisiva es aplicaciones orientadas a documentos.

## Diferencia importante

DynamoDB también guarda documentos, pero su modelo de acceso y API son distintos.
