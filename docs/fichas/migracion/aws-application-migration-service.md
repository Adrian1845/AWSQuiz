# AWS Application Migration Service

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Replica servidores y facilita migración de aplicaciones a AWS.

## Cuándo elegirlo

Rehost.

## Detalles que deciden la respuesta

- Replica discos de servidores origen y facilita probar y lanzar instancias en AWS.
- Se orienta al rehost con pocos cambios de aplicación.

## Caso basado en escenario

**Situación:** Una flota de servidores físicos se migra con pocos cambios.

**Elección:** Application Migration Service. La pista decisiva es rehost.

## Diferencia importante

DMS mueve datos de bases; Application Migration Service mueve servidores y aplicaciones.
