# Amazon MSK

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Apache Kafka administrado.

## Cuándo elegirlo

Aplicaciones que requieren APIs y ecosistema Kafka.

## Detalles que deciden la respuesta

- Opera clústeres Apache Kafka compatibles con clientes Kafka.
- Conserva topics, particiones y ecosistema Kafka de una plataforma existente.

## Caso basado en escenario

**Situación:** Una plataforma ya usa productores y consumidores Kafka.

**Elección:** MSK. La pista decisiva es aplicaciones que requieren apis y ecosistema kafka.

## Diferencia importante

Kinesis Data Streams ofrece API AWS distinta; MSK responde a requisito Kafka.
