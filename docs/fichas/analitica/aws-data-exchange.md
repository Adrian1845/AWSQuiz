# AWS Data Exchange

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Descubre y consume datos de terceros.

## Cuándo elegirlo

Adquirir conjuntos de datos externos.

## Detalles que deciden la respuesta

- Permite suscribirse y acceder a productos de datos publicados por proveedores.
- Revisa licencia, formato, actualización y forma de entrega del conjunto de datos.

## Caso basado en escenario

**Situación:** Un analista necesita datos comerciales de un proveedor.

**Elección:** Data Exchange. La pista decisiva es adquirir conjuntos de datos externos.

## Diferencia importante

No sustituye Glue para transformar datos propios; facilita adquirir datos de terceros.
