# Amazon EMR

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Ejecuta marcos de big data como Spark.

## Cuándo elegirlo

Procesamiento distribuido configurable.

## Detalles que deciden la respuesta

- Ejecuta marcos distribuidos como Spark, Hive y Hadoop con opciones de capacidad.
- Útil para ETL o análisis donde se controla el framework y sus trabajos.

## Caso basado en escenario

**Situación:** Un trabajo Spark procesa terabytes de eventos.

**Elección:** EMR. La pista decisiva es procesamiento distribuido configurable.

## Diferencia importante

Glue simplifica ETL administrado; EMR ofrece más control del ecosistema big data.
