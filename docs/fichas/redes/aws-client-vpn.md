# AWS Client VPN

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Acceso VPN administrado para usuarios finales.

## Cuándo elegirlo

Empleados remotos que entran a redes AWS.

## Detalles que deciden la respuesta

- Los usuarios instalan cliente y se autentican para acceder a recursos de red privados.
- Configura rutas y autorizaciones por red o grupo de usuarios.

## Caso basado en escenario

**Situación:** Analistas desde portátiles deben acceder a una aplicación privada.

**Elección:** Client VPN. La pista decisiva es empleados remotos que entran a redes aws.

## Diferencia importante

Site-to-Site VPN une redes; Client VPN conecta dispositivos de usuarios.
