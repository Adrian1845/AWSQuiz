# AWS Cost Explorer

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Explora gasto y tendencias históricas.

## Cuándo elegirlo

Analizar qué servicio incrementó el coste.

## Detalles que deciden la respuesta

- Visualiza gasto por servicio, cuenta, etiqueta y periodo.
- Permite investigar tendencia y causa de aumentos de factura.

## Caso basado en escenario

**Situación:** La factura subió y se debe desglosar por servicio y etiqueta.

**Elección:** Cost Explorer. La pista decisiva es analizar qué servicio incrementó el coste.

## Diferencia importante

Cost and Usage Report entrega datos detallados para consultas propias; Cost Explorer ofrece exploración visual.
