# AWS Control Tower

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Configura y gobierna un entorno de múltiples cuentas.

## Cuándo elegirlo

Una landing zone.

## Detalles que deciden la respuesta

- Crea una landing zone con estructura y controles para múltiples cuentas.
- Account Factory facilita aprovisionar cuentas siguiendo el gobierno establecido.

## Caso basado en escenario

**Situación:** Una organización abre decenas de cuentas con controles base.

**Elección:** Control Tower. La pista decisiva es una landing zone.

## Diferencia importante

Organizations aporta la estructura y SCP; Control Tower añade configuración y gobierno de landing zone.
