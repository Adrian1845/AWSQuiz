# AWS Management Console

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Interfaz web para gestionar AWS.

## Cuándo elegirlo

Inspección y operación manual.

## Detalles que deciden la respuesta

- Interfaz web para crear, inspeccionar y operar recursos.
- Útil para exploración manual, aunque cambios repetibles convienen en plantillas o automatización.

## Caso basado en escenario

**Situación:** Un operador revisa visualmente una alarma y sus recursos.

**Elección:** Management Console. La pista decisiva es inspección y operación manual.

## Diferencia importante

CLI y API permiten automatizar; la consola sirve a interacción humana.
