# Amazon Managed Grafana

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Paneles Grafana administrados para diversas fuentes.

## Cuándo elegirlo

Observabilidad visual unificada.

## Detalles que deciden la respuesta

- Aloja espacios de trabajo Grafana para consultar y visualizar fuentes de datos.
- Se orienta a paneles de observabilidad compartidos y control de acceso.

## Caso basado en escenario

**Situación:** Operaciones quiere paneles de varias fuentes sin operar Grafana.

**Elección:** Managed Grafana. La pista decisiva es observabilidad visual unificada.

## Diferencia importante

CloudWatch es fuente de métricas y alarmas AWS; Grafana puede visualizar esa fuente junto con otras.
