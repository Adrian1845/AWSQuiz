# AWS Cost and Usage Report

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Datos detallados de coste y uso para análisis propio.

## Cuándo elegirlo

Informes granulares.

## Detalles que deciden la respuesta

- Exporta el detalle de cargos y uso a S3 para análisis.
- Úsalo para informes granulares y cruces con datos internos.

## Caso basado en escenario

**Situación:** Finanzas quiere analizar cargos en S3 con sus propias consultas.

**Elección:** Cost and Usage Report. La pista decisiva es informes granulares.

## Diferencia importante

Cost Explorer ofrece interfaz visual; el reporte permite trabajar con filas de datos.
