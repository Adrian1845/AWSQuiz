# AWS Well-Architected Tool

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Revisa una carga frente a pilares y buenas prácticas.

## Cuándo elegirlo

Identificar riesgos de arquitectura.

## Detalles que deciden la respuesta

- Organiza una revisión de carga contra pilares y preguntas de buenas prácticas.
- Produce riesgos y un plan de mejora que debe priorizar el equipo.

## Caso basado en escenario

**Situación:** Antes de producción se evalúan seguridad y resiliencia.

**Elección:** Well-Architected Tool. La pista decisiva es identificar riesgos de arquitectura.

## Diferencia importante

Trusted Advisor evalúa comprobaciones de cuenta; Well-Architected Tool guía una revisión de arquitectura por carga.
