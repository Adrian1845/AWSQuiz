# AWS License Manager

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Gestiona reglas y uso de licencias de software.

## Cuándo elegirlo

Controlar licencias existentes.

## Detalles que deciden la respuesta

- Define reglas y rastrea uso de licencias en recursos compatibles.
- Ayuda a controlar restricciones de licencias al migrar software comercial.

## Caso basado en escenario

**Situación:** La empresa migra software con licencias por núcleo.

**Elección:** License Manager. La pista decisiva es controlar licencias existentes.

## Diferencia importante

Cost Explorer analiza cargos AWS; License Manager se centra en el cumplimiento de licencias.
