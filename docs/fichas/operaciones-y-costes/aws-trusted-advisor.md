# AWS Trusted Advisor

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Recomendaciones sobre configuración y buenas prácticas.

## Cuándo elegirlo

Revisar oportunidades de mejora.

## Detalles que deciden la respuesta

- Proporciona recomendaciones de buenas prácticas según comprobaciones disponibles.
- Revisa coste, rendimiento, seguridad, límites y resiliencia según plan y comprobación.

## Caso basado en escenario

**Situación:** Se buscan recursos o configuraciones que requieren revisión.

**Elección:** Trusted Advisor. La pista decisiva es revisar oportunidades de mejora.

## Diferencia importante

Compute Optimizer se centra en dimensionar recursos compatibles a partir de uso.
