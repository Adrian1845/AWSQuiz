# AWS Service Catalog

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Publica productos de infraestructura aprobados.

## Cuándo elegirlo

Autoservicio con control.

## Detalles que deciden la respuesta

- Los administradores publican productos aprobados basados en plantillas.
- Los usuarios pueden lanzar recursos estandarizados sin diseñar cada plantilla.

## Caso basado en escenario

**Situación:** Equipos deben desplegar solo plantillas de bases de datos aprobadas.

**Elección:** Service Catalog. La pista decisiva es autoservicio con control.

## Diferencia importante

Control Tower gobierna el entorno multi-cuenta; Service Catalog controla productos de autoservicio.
