# AWS Compute Optimizer

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Recomienda dimensionamiento de recursos compatibles según uso.

## Cuándo elegirlo

Ajustar capacidad y coste.

## Detalles que deciden la respuesta

- Analiza métricas de utilización y recomienda tamaños o configuraciones compatibles.
- Antes de aplicar una recomendación, comprueba picos, licencias y requisitos de rendimiento.

## Caso basado en escenario

**Situación:** Instancias sobredimensionadas deben identificarse con métricas.

**Elección:** Compute Optimizer. La pista decisiva es ajustar capacidad y coste.

## Diferencia importante

Cost Explorer muestra gasto; Compute Optimizer propone cambios técnicos de capacidad.
