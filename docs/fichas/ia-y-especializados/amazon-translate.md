# Amazon Translate

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Traduce texto entre idiomas.

## Cuándo elegirlo

Contenidos multilingües.

## Detalles que deciden la respuesta

- Traduce texto entre idiomas mediante API.
- Útil para catálogos, mensajes o contenidos multilingües a escala.

## Caso basado en escenario

**Situación:** Mensajes de clientes deben mostrarse en otro idioma.

**Elección:** Translate. La pista decisiva es contenidos multilingües.

## Diferencia importante

Comprehend clasifica y analiza texto; Translate produce texto en otro idioma.
