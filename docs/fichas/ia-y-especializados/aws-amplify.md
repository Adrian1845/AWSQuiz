# AWS Amplify

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Herramientas y hosting para aplicaciones web/móviles.

## Cuándo elegirlo

Acelerar frontends integrados con AWS.

## Detalles que deciden la respuesta

- Incluye herramientas para crear y alojar frontends conectados a servicios AWS.
- Puede integrar despliegue continuo del frontend desde repositorios.

## Caso basado en escenario

**Situación:** Un frontend necesita hosting y flujo de despliegue administrados.

**Elección:** Amplify. La pista decisiva es acelerar frontends integrados con aws.

## Diferencia importante

CloudFront es CDN; Amplify añade flujo de desarrollo y hosting de aplicación.
