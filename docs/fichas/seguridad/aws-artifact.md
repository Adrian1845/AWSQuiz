# AWS Artifact

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Acceso a informes y acuerdos de cumplimiento de AWS.

## Cuándo elegirlo

Evidencias de auditoría.

## Detalles que deciden la respuesta

- Da acceso a documentos de cumplimiento y acuerdos de AWS.
- Sirve como evidencia sobre controles del proveedor en auditorías.

## Caso basado en escenario

**Situación:** Un auditor solicita un informe de conformidad de AWS.

**Elección:** Artifact. La pista decisiva es evidencias de auditoría.

## Diferencia importante

No analiza la configuración de tu cuenta; para eso compara AWS Config y Security Hub.
