# AWS Security Hub

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Centraliza hallazgos y controles de seguridad.

## Cuándo elegirlo

Vista consolidada entre cuentas.

## Detalles que deciden la respuesta

- Agrega hallazgos de productos de seguridad y evalúa controles de seguridad.
- Facilita una vista central de cuentas, prioridades y flujos de respuesta.

## Caso basado en escenario

**Situación:** Seguridad necesita priorizar hallazgos de GuardDuty e Inspector.

**Elección:** Security Hub. La pista decisiva es vista consolidada entre cuentas.

## Diferencia importante

No sustituye las fuentes de detección como GuardDuty o Inspector; reúne sus resultados.
