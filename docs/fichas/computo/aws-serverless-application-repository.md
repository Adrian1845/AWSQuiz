# AWS Serverless Application Repository

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Catálogo de aplicaciones sin servidor reutilizables.

## Cuándo elegirlo

Desplegar componentes publicados.

## Detalles que deciden la respuesta

- Distribuye aplicaciones sin servidor empaquetadas para su despliegue y reutilización.
- Revisa permisos y recursos incluidos antes de instalar una aplicación publicada.

## Caso basado en escenario

**Situación:** El equipo busca una aplicación Lambda empaquetada y reutilizable.

**Elección:** Serverless Application Repository. La pista decisiva es desplegar componentes publicados.

## Diferencia importante

No ejecuta código por sí solo: Lambda y otros recursos de la aplicación desplegada realizan el trabajo.
