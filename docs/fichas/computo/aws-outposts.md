# AWS Outposts

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Extiende infraestructura y servicios AWS a instalaciones propias.

## Cuándo elegirlo

Procesamiento local con requisitos de residencia o latencia.

## Detalles que deciden la respuesta

- Proporciona hardware AWS instalado en la ubicación del cliente y conectado a una región principal.
- Evalúa residencia, latencia local, conectividad y servicios admitidos antes de elegirlo.

## Caso basado en escenario

**Situación:** Una fábrica necesita procesamiento AWS junto a máquinas locales.

**Elección:** Outposts. La pista decisiva es procesamiento local con requisitos de residencia o latencia.

## Diferencia importante

Direct Connect conecta redes con AWS; Outposts ubica infraestructura AWS físicamente en el sitio.
