# VMware Cloud on AWS

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Ejecuta entornos VMware en infraestructura AWS.

## Cuándo elegirlo

Migrar o ampliar cargas VMware.

## Detalles que deciden la respuesta

- Conserva herramientas y modelos operativos VMware sobre infraestructura AWS.
- Sirve para extensión o migración de máquinas virtuales cuando el cambio de plataforma no es inmediato.

## Caso basado en escenario

**Situación:** Una empresa necesita extender su operación VMware existente a AWS.

**Elección:** VMware Cloud on AWS. La pista decisiva es migrar o ampliar cargas vmware.

## Diferencia importante

Migrar a EC2 cambia la plataforma de virtualización y la operación; VMware Cloud on AWS preserva ese entorno.

AWS indica que dejó de revender VMware Cloud on AWS en 2024 y que el servicio continúa disponible a través de Broadcom. Estudia esta entrada como opción de migración VMware existente y verifica las condiciones actuales antes de proponer una adquisición nueva.
