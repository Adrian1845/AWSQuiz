# AWS Wavelength

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Acerca recursos AWS al borde de redes de telecomunicaciones.

## Cuándo elegirlo

Aplicaciones móviles sensibles a latencia.

## Detalles que deciden la respuesta

- Sitúa capacidad de cómputo y almacenamiento cerca de redes 5G de operadores compatibles.
- El caso de uso es latencia móvil extremadamente baja hacia dispositivos de esa red.

## Caso basado en escenario

**Situación:** Un juego móvil necesita procesar cerca de usuarios de una red 5G compatible.

**Elección:** Wavelength. La pista decisiva es aplicaciones móviles sensibles a latencia.

## Diferencia importante

CloudFront acerca contenido cacheable; Wavelength acerca ejecución de aplicaciones.
