# AWS Elastic Beanstalk

[← Índice de servicios](../../guia-estudio-saa-sdd.md) · Revisión: 2026-10-23

## Qué hace

Despliega una aplicación y gestiona recursos de plataforma subyacentes.

## Cuándo elegirlo

Una web tradicional con poca gestión operativa.

## Detalles que deciden la respuesta

- Recibe una versión de aplicación y crea un entorno con cómputo, escalado y despliegue.
- Permite elegir plataformas soportadas y conserva acceso a la configuración de recursos subyacentes.

## Caso basado en escenario

**Situación:** Un equipo entrega código web y quiere despliegue administrado.

**Elección:** Elastic Beanstalk. La pista decisiva es una web tradicional con poca gestión operativa.

## Diferencia importante

App Runner o Lambda simplifican otros modelos; Beanstalk conviene a aplicaciones web tradicionales que siguen necesitando entorno de servidor.
