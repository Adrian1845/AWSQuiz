## Explanation

The correct answer is **Amazon RDS**.

## Why the other options are incorrect

- **Amazon DynamoDB:** Amazon DynamoDB is a key-value, document, NoSQL database. It does not have SQL and does not store the data in a relational format, but can be used for transactional processing.
- **Amazon ElastiCache:** Amazon ElastiCache is a caching technology and it doesn't have SQL capabilities.
